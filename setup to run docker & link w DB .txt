  MASTER HUB — Docker Setup Guide


FIRST TIME / NEW MACHINE
1. Make sure Docker Desktop is installed and running.
2. Open a terminal in the project root (Master_Hub folder).
3. Run:
      docker compose up --build

   This will:
   • Download MySQL 8.0, phpMyAdmin, PHP 8.3, Node 20
   • Install Composer & PHP dependencies
   • Install npm & Node.js dependencies
   • Auto-run database migrations
   • Start all 4 services

AFTER THE FIRST TIME (no rebuild needed)
   docker compose up


SERVICES & PORTS
   Frontend  (React + Vite)   → http://localhost:5173
   Backend   (Laravel API)    → http://localhost:8000
   phpMyAdmin (DB GUI)        → http://localhost:8080
   MySQL                      → localhost:3307

STOP ALL CONTAINERS
   docker compose down

STOP & DELETE DATABASE DATA (full reset)
   docker compose down -v

RUN A MIGRATION MANUALLY
   docker exec master_hub_backend php artisan migrate

OPEN A SHELL INSIDE A CONTAINER
   docker exec -it master_hub_backend bash     (Laravel)
   docker exec -it master_hub_frontend sh      (React)
   docker exec -it master_hub_db bash          (MySQL)
